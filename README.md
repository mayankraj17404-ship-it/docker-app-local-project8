# Project 8: Build and Run Docker App Locally

## Overview
This project demonstrates how to containerize a simple web application using Docker and run it locally inside a container.

## Objective
Practice container deployment by creating a Docker image and running a web application in a Docker container.

## Technologies Used
- Docker
- Dockerfile
- Nginx
- HTML
